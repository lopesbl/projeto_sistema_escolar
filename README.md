# EducaTech - Sistema de Acompanhamento Escolar 🎓

Um painel web (dashboard) responsivo voltado para a gestão e acompanhamento do desempenho escolar. O sistema permite a visualização de métricas, cadastro de alunos, controle de frequência e gerenciamento de atividades.

Este projeto foi desenvolvido para fins de estudo e prática de desenvolvimento Front-End, integrando o portfólio acadêmico do curso de Análise e Desenvolvimento de Sistemas da Universidade Cruzeiro do Sul.

## 🛠️ Tecnologias Utilizadas

* **HTML:** Estruturação semântica da aplicação.
* **CSS:** Estilização, layout (Flexbox/Grid) e responsividade.
* **JavaScript:** Lógica de interface e manipulação do DOM.

## ✨ Funcionalidades

* **Dashboard Interativo:** Visão geral de alunos, professores, matérias e atividades pendentes.
* **Gestão de Alunos:** Interface para consulta e cadastro de informações dos estudantes.
* **Controle de Frequência:** Tabela dinâmica para acompanhamento de presenças e faltas por matéria.
* **Atividades e Trabalhos:** Controle de tarefas, status de entrega e prazos.
* **Design Responsivo:** Interface adaptada para uso em diferentes tamanhos de tela.
